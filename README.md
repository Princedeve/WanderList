WanderList – Full-Stack Travel Listing Web Application 

Technologies: Node.js, Express.js, MongoDB, Mongoose, EJS, Bootstrap, Leaflet, OpenStreetMap, Nominatim, MVC

• Developed a full-stack travel listing application using Node.js, Express.js, MongoDB, and EJS.

• Implemented CRUD operations for creating, viewing, updating, and deleting travel listings.

• Followed MVC architecture with separate routes, controllers, models, and views.

• Implemented user authentication, authorization, reviews, and ratings for listings.

• Integrated Leaflet and OpenStreetMap to display dynamic maps and location markers for travel listings.

• Used Nominatim for geocoding locations into latitude and longitude and stored coordinates as GeoJSON data in MongoDB.

• Designed responsive and reusable web pages using EJS and Bootstrap.
